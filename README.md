# Bible Reader content — UG-Uighur,_Uyghur

This repository contains the Bible Reader SD-card content for **UG-Uighur,_Uyghur**.

## Directory layout

- `text/UG-Uighur,_Uyghur/` — all Bible translations and their original nested folder structure.
- `audio/UG-Uighur,_Uyghur/` — audio Bible book folders and chapter MP3s.
- `gospel/UG-Uighur,_Uyghur/` — Gospel files, retaining original names such as `Gospel.txt` and `Gospel.mp3`.

Copy these folders into the root of the Bible Reader `SDCARD` staging directory.
Do not rename files or flatten directories: the firmware expects the original paths.
